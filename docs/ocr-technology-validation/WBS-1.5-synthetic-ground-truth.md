# WBS 1.5 評価画像の正解テキスト作成（暫定合成セット）

## 結論

50画像すべてについて、画像描画に使用する文字列そのものを正解テキストとして固定した。生成後のmanifestには画像ID、カテゴリ、画像ファイル、寸法、SHA-256、正解テキストを保存する。

## 正解データの管理

- 正解テキストの原本は`evaluation/cases.mjs`にUTF-8で定義する。
- generatorが描画文字列と同じ値を`manifest.json`へ書き出す。
- 画像ごとのSHA-256をOCR評価前に照合し、正解と画像の取り違えを防止する。
- 縦書きは右列から左列の順を正解の読み順とする。
- 表はタイトルの後、上から下、各行は左から右のセル順とする。

## CER正規化

主指標は次の正規化後にUnicode code point単位のLevenshtein距離を計算する。

1. Unicode NFKC正規化
2. 改行、タブ、連続空白を1つのASCII空白へ変換
3. 先頭・末尾空白を除去
4. `編集距離 / 正解文字数`をCERとする

改行・読み順の影響を確認するため、改行を保持して行末空白だけを除くstrict CERも併記する。

`src/evaluation/cer.ts`へ計算処理を実装し、日本語置換、全角半角・空白正規化、空文字を単体テストした。

## 制約

合成画像は正解が自明でラベル誤りを防げる一方、実画像固有の曖昧さを含まない。最終Gate承認前に、匿名化された実画像と人手確認済み正解テキストへ追加・置換する必要がある。

## 完了条件

50画像すべてに正解テキストと読み順を設定し、CERを自動算出できるため、暫定合成セットに対するWBS 1.5を完了と判定する。
