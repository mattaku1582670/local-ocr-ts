# WBS 1.4 OCR精度評価画像を収集（暫定合成セット）

## 結論

ユーザー承認に基づき、実画像セットが提供されるまでの暫定ベースラインとして、8カテゴリ・50件の合成評価画像を作成した。

画像はローカルのCanvasで決定論的に生成し、第三者画像、外部URL、個人情報、機密情報を含まない。WBS 1.4の最低50画像を満たすが、実際のWindowsスクリーンショットやカメラ撮影文書を置き換えるものではない。

## カテゴリ

| カテゴリ | 件数 | 条件 |
|---|---:|---|
| Windows UI | 7 | ヘッダー、パネル、操作ラベル |
| 白背景日本語文書 | 7 | 1273×1800、複数行文書 |
| 撮影風文書 | 6 | 傾き、影、背景グラデーション |
| 小さい文字 | 6 | 20px、日本語・英数字 |
| 英数字混在 | 6 | ID、金額、メール、電話番号 |
| 表 | 6 | 4列、罫線、数値 |
| 縦書き参考 | 6 | 右から左の3列 |
| 低コントラスト | 6 | 薄い文字と近い背景色 |
| 合計 | 50 | 仕様の評価カテゴリを網羅 |

生成画像の合計は7,699,518 bytesだった。各画像の寸法、バイト数、SHA-256をmanifestへ記録した。

## 再現方法

評価ケースは`evaluation/cases.mjs`、生成器は`scripts/generate-evaluation-set.mjs`へ定義した。

```text
npm run generate:evaluation-set
```

生成物は`evaluation/generated/v1`へ配置する。生成PNGは再生成可能なためGit管理対象外とし、ソースとなるケース定義と生成器だけを管理する。

## 目視確認

Windows UI、撮影風文書、表、縦書きの代表画像を目視し、空画像、文字切れ、表の崩れがないことを確認した。

## 制約

- 写真風画像はCanvas変換であり、実カメラのレンズ歪み、手ぶれ、圧縮ノイズを完全には再現しない。
- OSやフォント更新で描画ピクセルとSHA-256が変わる可能性がある。
- 実利用データによる最終精度評価は未実施である。

## 完了条件

8カテゴリ・合計50画像を生成・検証したため、暫定合成評価セットとしてWBS 1.4を完了と判定する。
